# 系统套装67

包含5张无印花效果底版、5尺码裁片底版、逐张区域蒙版及模板JSON，以及测试花型。

照片底版由参考照片经AI去除旧图案后制作，尺寸规范化至原照片大小；是可复用的二维模板，不声称恢复原始PSD或精确三维褶皱。保留reference.jpg供对照。

裁片在原始像素坐标内清除旧图案，保留轮廓及红色生产标记，未通过AI重绘形状；不自动改写旧货号标记。110DPI来自用户原文件，未经过工厂物理标尺校准。

模板首次使用会复制到“文档/飞凡印花模板/系统套装67_v03”，编辑后不会在下次启动被覆盖。

OpenRaster（ORA）分层导出可用Krita或GIMP打开；模板PNG和mask.png也可分别导入其他图像编辑软件。
