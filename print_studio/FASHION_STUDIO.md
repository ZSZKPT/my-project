# 多版型样机工作台 v0.4（可运行开发版）

本版把版型、模特模板与印花分离。它是新架构与本地批量工作流的可运行版本，**不是 V1–V3 全部验收完成版**。本机和云环境都没有 Photoshop；没有把 PNG/ORA 改后缀伪装成 PSD，也没有声称实测过原生智能对象。

## 打开与第一次使用

Windows 下载包解压后运行 `飞凡印花设计.exe`。Python 用户安装 `requirements.txt`，在项目根目录运行 `python -m print_studio.main`。

1. **服装版型库**：内置 23 个分类/部件预设，覆盖 T恤、短裤、长裤、连衣裙、两件套、卫衣、背心。这里的“预设”不等于已有真实照片样机。导入新的 `garments.json` 可以增加类型，渲染引擎不判断具体衣服名称。
2. **模特模板库 → 新建**：为每张模特照片选择版型、模特ID与视角（如 main / side / back）。每张照片、每个视角独立保存底图和空蒙版；不借用另一模特的坐标。
3. 逐部件绘制/导入同尺寸灰度蒙版，白色区域印花。绘制**前景遮挡蒙版**，白色保护头发、皮肤、饰品及抽绳等不换花结构。双击预览可放大，新预览会关闭上一张。
4. “修改分区 / 平铺 / 透视”可增加、删除、合并部件，调整智能对象名称和每部件参数。没有袖子的连衣裙需删除空的 sleeves 分区及其智能对象映射。空分区禁止批准。
5. **印花素材库**导入图片、货号文件夹或 CSV / XLSX。每个部件默认跟随该货号的同一印花；也可以给选中部件指定另一个花型。版型模板不嵌入具体货号花型，换 200 款印花不用重建 200 份模板。
6. 本地套图预览，检查分类、所有蒙版与遮挡后点击“核对批准”。改图、蒙版或参数会使旧批准失效。
7. 在模板库按 Ctrl/Shift 选择多个模板，在**批量任务管理**选择 A/B/C/D 模式，先看预计数量，创建并开始。

普通用户仍可点击右上角**原套版 / 裁片工作台**使用 v0.3 功能，包括已授权的案例67、原图像 API 花型还原、ORA 导出和各尺码裁片。它与新多版型模板是独立格式，旧任务不强行迁移。

## 分区参数与素材

`mockup.json` 是模板唯一清单；只引用模板文件夹内相对路径。主要实体为 GarmentType / GarmentPart / PrintRegion / OcclusionMask / MockupTemplate / SmartObjectMapping / PrintAssignment / BatchJob / ExportPreset。

每个分区的 `params`：

| 参数 | 作用 |
| --- | --- |
| tile_px | 图案循环单元宽度，底图像素单位 |
| scale | 该部件独立缩放倍率 |
| rotation | 花型旋转角度 |
| offset_x / offset_y | 独立平移，像素单位 |
| quad | 4 个归一化坐标，顺序左上、右上、右下、左下；null 为不变形 |
| shade_strength | 0–1 明暗相乘强度；0 为完全覆盖旧图 |

例如 `quad: [[0.1,0.05],[0.95,0],[1,1],[0,0.9]]` 做局部透视映射，蒙版仍定义最终印花范围。四边形必须凸、不交叉。旋转作用于整个平铺平面，避免旋转小格子之间产生黑缝。

可为分区设置 `shade` 灰度贴图；留空时取底图亮度。已印花的底图会把旧花型亮度带入，必须先做干净底版，或把 shade_strength 设为 0。本版是二维透视及明暗合成，**没有自动恢复三维褶皱、网格UV、位移图或工厂精确对花**。

`preset` 支持 JPG质量、输出宽高与裁剪框（left/top/right/bottom）。默认保留原尺寸；填宽高时居中裁剪适配。模板搜索、分类、复制、导入导出已实现；删除移入库内 `.trash`，不会删除外部原图。复制只复制同一张照片的样机副本，新模特应“新建”。

## 货号与队列

CSV 须为 UTF-8，XLSX 读取活动表。表头：

```csv
货号,印花路径,模板ID
YQ001,YQ001/print.png,
YQ002,YQ002/print.png,tpl_某个模板ID;tpl_另一个模板ID
```

相对路径按表格所在文件夹解析。货号有前导0时，在Excel把单元格设为文本。货号目录形式为 `根目录/YQ001/print.png`；有多个非 print 图片时要求表格明确指定，避免选错图。

模式 A 选择一个模板、多印花；B 同一版型、同一花型的多模特/视角；C 同一花型跨多个版型；D 自由组合。表格的模板ID能进一步限制每个货号适用的模板，界面按实际组合计算数量。

默认输出 `output/货号/视角.jpg`。同视角名称冲突会**阻止建任务**，提示加入 `{model}` 或 `{index}`，不会悄悄覆盖。命名还支持 `{sku}`、`{garment}`、`{template}`、`{print}`。

任务目录包含：

- `batch.json`：逐图片状态、参数和断点。
- `sources/`、`templates/`：不可变快照；原输入移动或删除后仍可继续。快照被修改会停止。
- `output/货号/`：商品 JPG。
- `temu-images.json`：按货号/模板列出已完成文件与 SHA256，供后续上架软件接入；不自动向 TEMU 发布。

暂停/取消在当前图片或 Photoshop 操作保存后生效。继续按原模板、印花、参数和输出目录运行；已完成项通过校验后跳过。失败项保留错误，点击“重试失败项”才重试；未知已有文件不会覆盖。图片已写入但进度尚未提交时意外断电，会保留该图片并提示人工核对，不盲目重新覆盖。`batch.json` 是新任务格式，不加载旧的“印花任务.json”或“飞凡上架任务进度.json”；旧任务从原工作台继续。

## Photoshop：明确的安装与验证边界

本地 JPG 后端无需安装 Photoshop。选择 Photoshop 后端时必须有 **Windows + 合法安装的桌面 Photoshop**，且该版本支持 COM / ExtendScript。当前用户没有安装 PS，所以**未验证任何目标PS版本**。

“准备原生PSD创建/验证脚本”只生成准备包，不会声称已经有 PSD。它包括：原图底板、逐分区花型/蒙版、遮挡图、预览、manifest 和 `create-and-verify.jsx`。

安装后在 Photoshop：**文件 → 脚本 → 浏览 → 选择 create-and-verify.jsx**。脚本尝试：

1. 为每个动态分区通过 Photoshop `newPlacedLayer` 创建原生智能对象，用分组蒙版控制范围。
2. 打开每个智能对象的内容，执行编辑/保存测试。
3. 添加前景遮挡保护，保存真实分层 PSD，再重新打开验证尺寸及智能对象类型。
4. 写入包含实际 Photoshop 版本、模板版本/指纹的 `photoshop-report.json`。

应用只接受与当前模板对应、报告通过且有真实 PSD 文件头的结果。报告不替代人工目测。Windows COM 批处理会执行相同脚本，每个任务产生独立 PSD/JPG；需要在目标版本实测后才能用于商业批量生产。

**重要限制**：本版把本地准备的平铺、旋转、透视与光影像素放在原生智能对象内部。对象可由 Photoshop 打开、缩放、旋转和编辑；更换原始图案、透视或平铺参数后在应用内重新准备。它**不是** Photoshop 原生可回退的透视网格/位移滤镜，也还不能原位替换已有PSD并保留其所有人工特效。暂不自动给用户安装 Photoshop，不用其他软件伪装通过。

## API 接入

当前已接入 OpenAI 兼容的 `chat/completions` 视觉 JSON 协议，可填写自有官方或兼容服务的完整 HTTPS 地址、实际支持图片输入的模型ID和 API Key。

- “读取模型列表”发起只读 GET `/models`，列出可见模型；模型可见不代表具备视觉能力。
- “导入照片并AI识别”分析类别、部件与多边形建议；然后“按AI建议新建模板”，复制匹配当前照片的分区草稿。识别失败可完全手动选择版型、画蒙版。
- “AI分析当前模特照片”与“应用AI多边形草稿”用于已有模板。应用会撤销审核；不允许把另一照片的建议坐标直接贴过来。
- 建议包含置信度、服装结构、遮挡及透视备注。**这不是像素级分割**，发丝边缘、半透明面料、复杂饰品都必须精修。
- 密钥只在内存，照片上传前确认；超时/限流不自动重发付费请求。模板和任务不保存密钥。服务商不支持 response_format/json_object 或图片输入时须适配文档。
- 当前无可用凭据，**没有进行真实付费 API 调用**。ChatGPT 网页会员不等于 API 用量，聊天工具中的 image_gen 也不是可打包进EXE的第三方API密钥。

旧工作台仍提供 OpenAI / DashScope 图像编辑 API，将模特效果图生成相似平面花型。它与本页服装识别是不同请求，不互相冒充。

## 验收与下一阶段

详见 [FASHION_ACCEPTANCE.md](FASHION_ACCEPTANCE.md)。本版本已进行 3 类技术图、不同蒙版与不同智能对象映射的实际本地渲染测试；**没有真实的长袖长裤、连衣裙模特素材/精修蒙版，没有 Photoshop 安装与API凭据，因此不声称满足全部严格验收**。

V1剩余：目标 Photoshop 版本真实运行/编辑/导出；真实短袖套装人工目测。
V2剩余：真实多视角、长袖长裤、连衣裙素材验收；原生PS变形与已有PSD原位替换增强。
V3剩余：像素级服装分割模型接入、褶皱/位移自动恢复、自动模板匹配与TEMU实际发布。
