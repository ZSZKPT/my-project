# 飞凡印花设计 v0.1

独立 Python 桌面应用，首版模式为**满版循环**，适合碎花、几何和已有无缝图案。可以本地批量铺图，也可通过图像编辑 API 将服装效果图重建为**相似花型**后再铺图。不是飞凡上架的更新，不会登录店铺或发布商品。

## 启动

Windows 打包版：解压 `FeifanPrintStudio-Windows.zip`，双击 `飞凡印花设计.exe`。无需安装 Python。

源码版需要 Python 3.11+、Tk 和 Pillow：

```sh
python -m pip install -r print_studio/requirements.txt
python -m print_studio.main
```

Linux 如缺少 Tk，需使用带 Tk 的 Python 安装。默认输出到用户文档下的“飞凡印花输出”，可自行选择。

## 本地批量铺图

1. 选择图片或导入文件夹，支持 PNG/JPG/WebP/TIFF/BMP，文件夹递归读取，最多1000张。请勿将输出目录放入输入目录，避免重扫输出。
2. 输入“循环单元宽度/cm”（整个输入花型单元对应的实际宽度），画布宽高、DPI和横纵偏移。
3. 在套版模板页选择一个或多个模板。可移除全部模板，只生成平面印花画布。默认附带平铺T恤示意模板和几何测试花型。
4. 本地模式不要勾选API还原；点击“预览选中图片”检查比例，再“新建并开始”。
5. 在输出目录审核 `平铺检查_2x2.png`。重复铺图不等于自动修成无缝图；边界有接缝需要修正输入花型。

每个输入图片独立编号，同名文件也不会相互覆盖。应用复制输入和模板到新的任务目录，不改名、覆盖或删除原图。输入PNG的透明区域在RGB转换时采用原始RGB色值；建议先提供底色完整的平面花型。

## 自制套版模板

模板由服装底图和**同尺寸、无透明通道的灰度蒙版**组成：白色区域印花，黑色区域保留，灰色柔化边缘。灰度内容会直接决定合成范围，不会自动推断衣服区域。

- 可先点击“绘制服装蒙版”，选择底图，用画笔涂抹需要印花的区域，橡皮擦修正，支持20步撤销，保存为灰度PNG。首版画笔在屏幕预览分辨率下绘制，再映射至底图；细小边缘建议用专业图像工具精修。
- 点击“创建套版模板”，选择底图、蒙版和保存目录。程序创建新文件夹，不覆盖所选原图。
- “整张底图对应宽度/cm”定义效果图的比例基准，不是实测胸围。与循环单元宽度一起控制花朵显示大小。
- 保留明暗使用底图亮度相乘，适合浅色衣服。彩色或深色底图可关闭此选项；首版没有位移图、透视网格和三维布料变形，不能声称与照片褶皱精确贴合。
- 多个模板可分别表示正面、背面或不同款式。同一花型会应用至所有已选模板。

模板文件示例：

```json
{
  "name": "长袖衬衫正面",
  "mode": "full_repeat",
  "base": "base.png",
  "mask": "mask.png",
  "canvas_width_cm": 65
}
```

三个文件应放在同一模板文件夹。可通过“导入模板 JSON”复用。

## OpenAI 图像 API 还原相似花型

默认接口为 `https://api.openai.com/v1/images/edits`，使用 OpenAI API 密钥。ChatGPT 网页订阅不包含 API 用量。“ChatGPT Image 2.0”的界面名称不能直接作为 API 模型 ID；请填写账户实际支持的图像模型 ID，本版本不声称已核实具体2.0型号或进行付费实测。

1. 导入模特/服装效果图，勾选“先通过 API 将效果图还原为相似花型”。
2. 在API页填写**完整的HTTPS接口地址、实际图像模型ID、协议、输出尺寸和密钥**。OpenAI兼容接口可点击“读取账户可用图像模型”查询名称含 image 的模型（不生成图片），再从下拉框选择；平台未开放模型列表时按文档手填。可修改内置提示词。
3. 协议适配：
   - **OpenAI兼容图像编辑**：multipart POST，字段 `model`、`prompt`、`image`、`n=1`、`size`；识别 `data[].b64_json` 或 `data[].url`。
   - **DashScope同步多模态**：JSON POST，`input.messages[].content`包含参考图 data URL 与 text；识别 `output.choices[].message.content[].image`。输出尺寸以 `1024*1024` 形式发送。
4. 接口必须支持所选协议、参考图 data URL/上传方式、尺寸及参数。模型名相似不代表API兼容。**QwenCloud 的真实请求格式未获得文档验证，不预设其地址，也未进行付费实测。** 如果服务商要求异步任务、其他认证/字段，需要补充适配器。
5. 参考图最长边压缩至2048像素并去除EXIF后上传。每次仅请求一张候选图。API结果不是原花型的精确复原，也不保证四边像素级无缝。
6. 软件内有上传与计费确认、本次调用上限。API价格以服务商实际账单为准，不硬编码固定单价。

### 计费与中断

- 发送前记录请求标记，收到响应后立即保存。结果下载失败，可在继续任务时复用响应重新下载，不重新生成。
- 网络超时、5xx或未识别响应可能已经计费，**不自动重发**。请先在服务商平台核对结果和费用。确需再次付费生成时，点击“允许重试未返回请求”后继续。
- 401/403/400等明确拒绝会显示通用提示，不输出可能包含密钥的原始报错。修正密钥后可继续；已保存的API地址和模型按任务快照沿用。
- 密钥仅保留在当前进程内，不写入模板、任务或导出的API配置。程序不主动记录请求头。API响应可能含临时签名图片链接，请勿把整个任务目录发布到公共仓库。
- 不支持浏览器登录态抓取或自动登录服务商网站。

## 任务继续及输出

点击“暂停”后等待当前图片/已发出的API请求保存，再退出。重新打开后加载 `印花任务.json`，点击“继续任务”。沿用原任务参数和模板快照，已完成输出经过SHA256校验后复用，不重新渲染。移动任务时复制**整个任务文件夹**，不要只移动JSON。原始输入丢失也不影响完整任务快照续作。

```text
印花任务_时间_编号/
  印花任务.json
  生成清单.csv
  sources/                  输入快照
  templates/                模板快照
  0001_货号/
    AI花型.png               仅API模式
    花型单元.png
    平铺检查_2x2.png
    满版印花画布.png           写入DPI元数据
    套版效果_01.png            每个模板一张
    生成参数.json
```

大图限制为单张3600万像素，DPI最高600，画布上限300cm，实际受总像素限制。先降低尺寸或DPI测试。**满版画布不是工厂裁片**，不包含真实版型、尺码放码、缝份、对花定位或印厂ICC色彩管理，生产前必须审核和打样。

后续模式可在模板 `mode` 和渲染分发处扩展定位印花、分区配色、跨片对花；v0.1不会显示尚未实现的模式入口。
