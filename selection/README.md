# 飞凡选款 · 浏览器采集选款库

在线网址：https://zszkpt.github.io/my-project/

## 当前采集方式

使用自己的 Chrome 扩展采集，Pinterest 来源为你的登录账号首页推荐，不是关键词搜索。Chrome 扩展安装和运行说明见仓库 browser-collector/README.md。原先的云端匿名定时采集已停用；旧采集工作流仅保留手动诊断。

在 Chrome 登录对应平台后，点击扩展“采集当前页”，再点“同步在线表格”。网页保留已有收藏、备注、评分和审核状态。也可以先导出 JSON，再用网页“导入数据”。个性化推荐数据不会上传服务器或公开仓库，只保存在本浏览器。

勾选平台并授权后，可由扩展每天北京时间 09:00 开新标签采集。电脑和 Chrome 必须保持运行；浏览器关闭时不采集。遇到验证需用户处理。首次成功采集建立基准，之后新发现才计入新增；不保证全店完整覆盖，首次发现不等于上架日期。

## 选款功能

- 商品图片卡片 / 表格，平台、标题、标签、日期、审核状态筛选。
- 收藏、备注、评分、相似标签整理；手动添加记录。
- 公开点赞 / 收藏数门槛筛选、排序；未公开的指标留空。
- Pinterest 首页可能包含其他兴趣内容，请人工按 wallpaper、无缝图案、设计等筛选；“无缝”需核验平铺效果。
- JSON 导入 / 完整备份、CSV 导出。请定期备份，清理浏览器数据或卸载扩展可能删除记录。

## 发布

网页由 GitHub Pages 托管，selection 文件变化后工作流自动发布。下载离线包需要保留 index.html 和 sync.js；扩展直接同步需要打开上方在线网址，离线版可通过 JSON 导入。

新增评价数量门槛、评价优先排序，以及同链接多复色 / 单色 / 未知筛选。颜色选项是商品实际选项，不根据图片配色推断。未显示完整总数时只记录可见下限；可在编辑商品中手动补充经确认的颜色数量及名称。

## 下载自己已收藏的原图

采集并同步后，在商品卡片点击★收藏，再点击网页上方“下载已收藏图片”。这里指个人星标，不是商品的公开收藏数。默认下载全部个人收藏，不受搜索/平台等显示筛选影响；若勾选了记录，则只下载所选记录中已收藏的图片。示例插画、没有HTTPS原图的记录跳过，相同原图URL去重，已完成/排队的下载不重复启动。

需要Chrome采集扩展1.5.0。网页下方“下载/更新采集扩展”提供ZIP；解压后在chrome://extensions开启开发者模式，加载含manifest.json的目录。更新已有扩展建议覆盖原扩展目录后点击扩展卡片的刷新按钮，再刷新在线表格。也可在扩展弹窗直接点“下载已收藏图片”，会读取当前已打开选款表里的最新星标收藏。

新下载保存到Chrome默认下载目录的“飞凡选款/我的收藏/北京时间日期/”。网页反馈的是启动排队数量，实际完成/失败以Chrome下载记录及扩展统计为准。服务器拒绝、登录失效等不冒充下载成功，原收藏和备注保留。每批最多1000张；更多收藏可勾选部分分批下载。

ZIP通过既有GitHub Pages构建脚本生成，不上传个人收藏数据、不新增工作流写权限。`scripts/package_browser_collector.py`生成扩展ZIP和collector-build.json校验信息。

验证：`node --test tests/browser-collector.test.mjs tests/browser-zip.test.mjs` 检查采集、个人星标/公开指标区分、重复请求串行、弹窗读取最新收藏和ZIP。`tests/selection-favorites-browser.cjs`用Chromium检查真实网页及桥接脚本，包含未安装扩展提示、全收藏/勾选范围、取消收藏立即生效和备注保留。当前云端Chromium管理员策略禁止加载未打包扩展，所以该界面测试模拟chrome.runtime，后台下载API契约由Node测试验证；未据此声称已验证真实平台图片服务器的下载可用性。
