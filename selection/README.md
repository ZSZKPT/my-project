# 飞凡选款 · JS 网页

独立静态网页，无需安装 Node 或依赖，双击 `index.html` 即可打开，也可将该文件上传至自己的 HTTPS 静态网站空间。

- 卡片 / 表格两种视图，平台、关键词、审核状态、新发现 / 近期 / 有公开销量筛选。
- 收藏、评分、备注、手动添加 / 编辑 / 删除、图片放大、批量选择收藏。
- JSON 导入与完整备份；CSV 导出当前结果或所选商品。导入示例可在“数据与导入”页面下载。
- 导入按平台 + 站点 + 商品 ID 合并，保留已有收藏、审核状态、评分和备注。
- 默认六条示例均有明显标识，图片为内置示意插画，非采集结果。可以清空示例。
- 登记用户提供的 Temu 店铺、SHEIN 美国店铺、LightInTheBox print top 搜索页；尚未连接爬虫或定时监控。
- 数据只保存在当前浏览器，不跨设备同步。请定期备份 JSON；浏览器清理数据会移除本地记录。CSV 是查看格式，不是完整恢复备份。
- 无公开销量时显示未知；首次发现不代表实际上架时间。不推算访问量、点击量。

在线部署仅需托管 `index.html`，无密钥、无后台。在线部署不会自动接通平台采集，也不会把数据同步给其他用户。远程商品图片是否加载取决于来源服务是否允许访问。

## 发布到 GitHub Pages

仓库提供手动工作流 `Publish Selection Web to Pages`。先在仓库 Settings → Pages → Build and deployment 将 Source 设置为 GitHub Actions，再到 Actions 运行该工作流。成功后的工作流环境链接才是实际在线网址。该工作流发布本选款网页至仓库 Pages 根目录；如仓库已有其他 Pages 网站，请先确认是否替换。此交付尚未运行发布工作流，也没有声称已上线。

## Pinterest 灵感

已登记 wallpaper、seamless pattern、surface pattern design 三个关键词来源。支持 Pinterest 图片记录、公开点赞数 / 收藏数、100 / 500 / 1,000 互动门槛、分别按点赞或收藏排序，以及“未核验 / 已核验 / 不适用”的无缝拼接核验字段。字段未知时留空，不能用推测补齐；仅收录参考链接和已有数据，目前不自动访问 Pinterest。页面中的“收藏”是你自己的选款标记，“公开收藏数”是来源平台的公开指标，两者独立。
