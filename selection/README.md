# 飞凡选款 · 在线每日选款库

独立 JS 网页，支持 Temu / SHEIN / LightInTheBox / Pinterest，卡片和表格视图，筛选、收藏、评分、备注，JSON 导入 / 备份和 CSV 导出。用户的选款决定保存在各自浏览器，不跨设备同步，请定期备份。

## 在线每日运行

仓库工作流 `Daily Selection Collection` 默认每天北京时间 09:00 运行（GitHub 调度可能延迟，长期无仓库活动可能暂停定时工作流）。也可在 Actions 手动运行。你的电脑和浏览器不需要开机。

每次任务依次读取六个目标的公开页面，检查 robots.txt，最多滚动 4 次、每个目标最多识别 120 条。只采集公开可见的商品链接、标题、图片和明确显示的指标；不绕过验证码、不注入登录 Cookie。遇到规则禁止、登录、验证码或访问失败时保留上次结果，并记录各目标的具体状态。没有识别到商品不会被当作成功。

首次成功采集建立“首采基准”，后续才记录新发现；首次发现不代表实际上架日期。保留最近 90 天的每商品指标快照，不因某次未找到商品而删除旧记录。结果在 `data/latest.json`，云端提交此公开数据到仓库后发布网页，因此不要在其中加入私密信息或账号凭据。

Temu、LightInTheBox 和 Pinterest 暂按美国地区环境请求；平台实际显示地区仍可能受 IP 等因素影响。目标配置在仓库 `selection-crawler/targets.json`。

## 启用在线网址

1. 仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。
2. 到 Actions 运行 **Daily Selection Collection**（首次代码推送也会触发）。
3. 工作流 publish 阶段成功后，打开 github-pages 环境提供的实际网址。

Pages 未配置时，采集仍可执行并保存结果和下载包，但网页不会自动上线。数据发布所需的仓库写入权限或分支保护若不允许 Actions 提交，需要仓库管理员调整。该设置不能通过本地 Git 推送替你开启。

网页打开时读取同站点 `data/latest.json`，之后每 5 分钟刷新。按钮“更新采集结果”读取最近结果，不立即触发云端爬虫。收藏、备注、评分和审核状态不会被刷新覆盖。页面展示云端最近运行时间、成功目标数量、各目标最近成功时间和失败原因。

## 指标解释

- 销量 / 评论 / 点赞 / 公开收藏数分别保存；未知不推算。“1,000+ sold”等保留原文，不作为精确销量。
- Pinterest 提供 wallpaper / seamless pattern / surface pattern design 三个来源。支持按公开点赞或收藏筛选，但来源不公开这些数字时无法筛选高互动。
- “我的收藏”是自己的选款标记，与来源平台的公开收藏数不同。
- 无缝标签需人工核验，不能仅凭关键词判定可平铺。
- 受站点页面、加载范围、地域与规则限制，不能保证全店新款覆盖或所有平台采集成功。请以实际每次报告为准。

## 下载使用

下载包需保留 `index.html`、`sync.js`、`data/` 的相对位置。双击网页可离线管理和导入记录；读取在线结果需要使用部署网址。若浏览器限制本地文件，使用静态服务器：`python -m http.server 8000 --directory selection`，再在本机浏览器打开对应端口。

CSV 是查看格式；JSON 备份用于完整恢复，导入按平台 + 站点 + 商品 ID 合并，保留已有选款决定。六条插画示例有明确标识，读取到已运行的真实数据源后自动移除，绝不会作为真实采集结果展示。
