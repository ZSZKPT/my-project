# 飞凡选款 · 浏览器采集选款库

在线网址：https://zszkpt.github.io/my-project/

## 当前采集方式

使用自己的 Chrome 扩展采集，Pinterest 来源为你的登录账号首页推荐，不是关键词搜索。Chrome 扩展安装和运行说明见仓库 browser-collector/README.md。原先的云端匿名定时采集已停用；旧采集工作流仅保留手动诊断。

在 Chrome 登录对应平台后，点击扩展“采集当前页”，再点“同步在线表格”。网页保留已有收藏、备注、评分和审核状态。也可以先导出 JSON，再用网页“导入数据”。个性化推荐数据不会上传服务器或公开仓库，只保存在本浏览器。

勾选平台并授权后，可由扩展每天北京时间 09:00 开新标签采集。电脑和 Chrome 必须保持运行；浏览器关闭时不采集。遇到验证需用户处理。首次成功采集建立基准，之后新发现才计入新增；不保证全店完整覆盖，首次发现不等于上架日期。

## 选款功能

- 商品图片卡片 / 表格，平台、标题、标签、日期、审核状态筛选。
- 收藏、备注、评分、相似标签整理；手动添加记录。
- 公开点赞 / 收藏数门槛筛选、排序；未公开的指标留空。
- Pinterest 首页可能包含其他兴趣内容，请人工按 wallpaper、无缝图案、设计等筛选；“无缝”需核验平铺效果。
- JSON 导入 / 完整备份、CSV 导出。请定期备份，清理浏览器数据或卸载扩展可能删除记录。

## 发布

网页由 GitHub Pages 托管，selection 文件变化后工作流自动发布。下载离线包需要保留 index.html 和 sync.js；扩展直接同步需要打开上方在线网址，离线版可通过 JSON 导入。

新增评价数量门槛、评价优先排序，以及同链接多复色 / 单色 / 未知筛选。颜色选项是商品实际选项，不根据图片配色推断。未显示完整总数时只记录可见下限；可在编辑商品中手动补充经确认的颜色数量及名称。
