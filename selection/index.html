本页为独立静态 JS 网页，可离线打开或部署到静态网站。收藏、备注和商品数据保存在当前浏览器；收藏和备注不上传到服务器。通过 Chrome 扩展同步当前浏览器的采集结果，状态以监控目标页面为准。

导入 JSON：支持商品数组或本页导出的完整备份。相同平台、站点、商品 ID 的记录会合并，保留你已有的收藏、评分、审核状态和备注。所有记录验证通过后才写入。

公开销量：精确数值填 sales；“1,000+”等显示值填 salesText，无法确认时 sales 留空，评论数单独记录。价格必须带币种。首次发现时间不代表实际上架时间。
导出：CSV 导出当前筛选结果，若有勾选则仅导出勾选项；完整 JSON 备份保留全部商品、监控目标和选款记录。示例记录始终带有“示例”标识。
Pinterest 使用你已登录浏览器的首页推荐，可按 wallpaper、无缝、设计等词筛选已有记录。点赞和收藏仅填写公开可核实的数据，未知时不计入互动门槛筛选；不能用评论或搜索排名替代点赞。无缝标签不代表图片可平铺，需人工核验后标记“已核验”。没有平台访问量或点击量来源，本页不推算流量。在线部署后数据仍按浏览器分别保存。
