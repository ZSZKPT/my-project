IMPORT MATERIALS

导入裁片文件

默认按110 DPI识别左右两片；保留全部识别到的图案、二维码、连接条和尺码。导入后直接排料，无需逐片确认。

背景识别无法理解缝线或白色印花。二维码、连接条和尺码作为原图内容参与间距检查并随片打印。识别失败会明确报错，不会自动删标签。
CONTOUR REVIEW

核对裁片与实际尺寸

绿色 = 裁片外轮廓；内部孔洞不用于套排

只预留空间，不自动生成缺失的出血图像。

无需逐片确认。此处只用于主动编辑；双片尺寸由原始像素与110 DPI确定。
MATCH BINDING STRIPS

按已排图片拉取包边条

每个已排原始图片文件匹配一张包边条，同图左右两片只匹配一次。不同导入实例即使文件名相同，也各取一张。

示例：款号-L-1.jpg → 款号-L-1包边条.jpg；也支持中间的横线、下划线或空格。

尚未选择总目录。默认查找其下的同款号文件夹，也可直接选择某个款号文件夹。

仅复制对应原文件，不改变排料、尺寸或DPI。例：YQ-TJGG-44-L-1.jpg → 总目录/YQ-TJGG-44/YQ-TJGG-44-包边条.jpg，每个原图各复制一张。缺失或匹配到多个文件时，先修正文件名或缩小扫描范围。
