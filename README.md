# Temu 印花上架工作台

面向全托管店铺的本地单用户工作台：按货号扫描图片、多产品模板、尺码/供货价/库存校验、批量生成草稿、去重、JSON 导出以及阻塞任务记录。

## 启动

需要 Python 3.12+，无第三方依赖。

```sh
cd /workspace/my-project
python3 app.py
```

默认只监听本机 8000 端口。数据库保存在忽略目录 `data/temu.sqlite3`。将图片放入 `data/images/`，支持 `ABC.jpg` 或 `ABC/01-main.jpg`、`ABC/02-detail.jpg`。目录形式以第一层目录名作为货号，目录中的图片按相对路径排序。仅支持 JPG、PNG 和 WebP。

可用环境变量 `TEMU_DATA_DIR`、`TEMU_IMAGE_ROOT`、`PORT` 更改数据目录、图片库和端口。配置项均不需要密钥。数据目录需自行备份。此版本无登录鉴权，仅用于可信本机环境，不应直接暴露到公网。

## 产品模板与上架状态

在印花名称表格中手动填写货号对应的印花名，再创建模板：填写复制来源商品编号、含 `{print_name}` 的标题、共用详情与尺码列表。选择货号和模板生成草稿，同一模板和货号自动去重。SKC = 文件夹货号，SKU = 货号-尺码。已有草稿为快照，不随名称表或模板更改自动更新。

**当前不会向 Temu 提交商品，也不会模拟提交成功。** JSON 导出是内部草稿，不是平台发布请求。尝试提交会生成阻塞任务。网页自动化尚未实现，目前只提供本机专用浏览器启动器，参见 [Windows 使用说明](windows/README.md)。

价格单位、币种、平台属性与尺码表需进一步验证。本机登录状态不得共享或提交到 Git。图片库使用完整商品图，不包含印花合成。

## 当前网页套版流程

接入方向已调整为卖家后台网页自动化，地址为 `https://agentseller.temu.com/goods/list`。目前已实现准备数据，尚未实现浏览器复制或发布。

图片库采用 `货号/货号命名的图片.jpg`。刷新后在“货号 → 印花名称”表格手动填写并保存名称。模板需填写复制来源商品编号，将原标题中需要替换的印花名称改成 `{print_name}`，其他标题文字保持原样。生成草稿时 SKC = 文件夹货号，SKU = 货号-尺码。未填写印花名时禁止生成。名称表持久保存在 SQLite，已生成草稿是快照，不会随表格修改自动更新。

截图中的“复制产品”为第三方插件入口，不能仅凭截图假定原生 Temu 支持该操作。后续需要连接用户已登录浏览器，验证具体复制页面和字段，以及图片替换、货号维护、草稿保存与发布行为。当前没有浏览器连接能力，未验证该页面。
