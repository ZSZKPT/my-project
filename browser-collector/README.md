# 飞凡选款 · Chrome 浏览器采集扩展

## 安装

解压完整目录，打开 Chrome 的 `chrome://extensions`，开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择包含 manifest.json 的目录。固定“飞凡选款”扩展到工具栏。

使用你平时登录各平台的 Chrome 用户配置，不使用自动化 Chromium，不读取密码、Cookie 或登录令牌。扩展初次安装只请求选款网页域名权限及本地存储、下载等功能。每天采集功能开启时才请求你勾选的平台页面读取权限。

## Pinterest 首页推荐

在你平时的 Chrome 登录 Pinterest，打开 https://www.pinterest.com/ 。确认是你的首页推荐后，点击扩展“采集当前页”。只读取已加载的 Pin 链接、标题、图片和公开指标，不读取个人账号设置。搜索页、画板和单 Pin 页面会提示改用首页。

推荐内容由 Pinterest 根据你的账号提供，扩展不会把关键词搜索伪装成首页推荐，也不会假定推荐图片全部是印花。平台未公开的点赞 / 收藏数留空。

## 每日采集

勾选需要的平台，点击“授权并开启”，在 Chrome 权限窗口确认。默认每天北京时间 09:00 新开采集专用标签，按页面正常加载结果，按设置的加载轮数和图片上限运行。电脑和 Chrome 必须运行；09:00 后首次启动 Chrome 会补跑当日任务。系统休眠或 Chrome 调度可能延迟。扩展停止或浏览器退出时不能持续采集；下次打开可以手动执行一轮。

采集器不会绕过验证，不点击验证码或模拟登录。受限标签会保留，请自行登录或处理验证后点击“采集当前页”。正在使用的其他标签不会被滚动或关闭。手动采集当前页不自动滚动。首次有结果建立首采基准，以后新发现才标记为新增，记录保存在扩展自己的本地存储。

## 在线表格

点击“同步在线表格”，会打开 https://zszkpt.github.io/my-project/ 并将采集记录写入该浏览器的选款库。已有收藏、评分、审核状态和备注保留。每日采集结束时若在线表格已打开，会自动发送；未打开时结果仍保存在扩展，稍后点同步即可。

这不是上传到公开仓库或服务器；个性化推荐记录仍只保存在你的浏览器，不会公开发布。其他电脑不会自动同步。可导出 JSON，再用选款网页“导入数据”。定期备份，卸载扩展或清理浏览器数据可能移除记录。

## 点赞、公开收藏筛选与图片下载

可分别勾选“点赞数大于”和“收藏数大于”，输入门槛。条件关系支持：

- 且 AND：所有启用的条件都满足。
- 或 OR：任意启用的条件满足。

例如点赞大于 100、收藏大于 500：AND 只下载同时满足的图；OR 下载任一项满足的图。阈值本身不入选。未知指标不满足该项条件；OR 下另一项已知且满足时仍可入选。“公开收藏数”与个人在选款表中的“我的收藏”不同。

点“查看符合数量”后再点“下载符合图片”。只下载扩展中已采集的图片，每条记录一张。下载到 Chrome 默认下载目录的“飞凡选款/条件组合/日期/”文件夹。已完成或进行中的图片跳过，中断的图片可以重试，同名文件不覆盖。完成状态看下载统计或 Chrome 下载记录。

在线表格也有点赞、收藏门槛和 AND / OR 关系；留空表示不启用该项。实际批量下载在扩展中执行。更新已安装的解压扩展后，在 chrome://extensions 点击扩展卡片的刷新按钮。

## 自动翻页抓取图片

打开目标店铺，或你已登录的 Pinterest 首页，在扩展中设置加载轮数（1–50）和图片上限（1–1000），点击“开始自动采集”。有分页控件时优先点下一页；Pinterest 自动滚动首页推荐。连续三轮无新增图片、达到轮数或图片上限、遇到验证时结束。“停止翻页”会在当前读取后停止，已经采集的记录保留。再次开始会从当前页面位置继续读取，已入库记录会去重。

当前采集标签页会滚动或跳到下一页；不要在同一标签同时进行其他浏览操作。Pinterest 支持普通 Pin 链接、带标题的 Pin 链接及带明确 Pin ID 的卡片，未识别时会展示页面链接和图片数量，便于定位页面差异。

## 下载图片 ZIP 包与失败排查

图片包范围可选“符合点赞 / 收藏条件”或“全部已采集图片”；后者无需点赞或收藏数。点击“下载图片 ZIP 包”。Chrome 会按需请求读取所选图片 CDN 域名的权限；这是读取图片二进制生成压缩包所需，不读取你的密码或 Cookie 内容。图片仍只在你的浏览器内处理，不上传到服务器。

每包最多 200 张、单张最多 15 MB、图片总计最多 150 MB。按原格式打包 JPEG / PNG / WebP / GIF / AVIF，不重新编码图片。部分失败时包内含“图片清单.json”和“下载失败说明.txt”；全部失败时直接提示，不会用登录页或拦截页冒充图片。单张已下载过的图片也可以重新加入 ZIP，ZIP 与逐张下载是独立操作。

- 没有图片域名权限：在 Chrome 访问提示中允许选中图片的域名，再重试 ZIP。
- 服务器返回 401 / 403：先用当前 Chrome 登录来源平台，重新采集有效图片链接；如果仍拒绝，回到来源页面用浏览器保存。扩展权限不能解除服务器限制。
- 下载目录不可写：在 Chrome 设置 → 下载内容中选择可写目录。
- Chrome 安全策略或系统阻止：点击“查看下载错误”，查看 chrome://downloads 的具体原因，不要直接关闭浏览器安全保护。
- ZIP 中有失败图片：查看包内说明，处理登录、过期链接或网络问题后重试。

更新版本后进入 chrome://extensions 刷新此扩展，并刷新在线选款页。新增 ZIP 权限在新版本中生效；图片域名仅在点击打包时逐项申请。

## 评价数量与同链接复色

扩展和在线选款表可筛选“评价数量大于”，支持和点赞、公开收藏数选择 AND / OR。数量是平台公开的评价 / 评论条数，星级分数不作为条数；没有明确数量时保持未知。

“同链接复色”是独立叠加条件，可选不限、多颜色（至少2个选项）、已确认单色、未知。只有同一个商品链接下明确显示的颜色总数、颜色选项才作为依据，不根据主图的色彩、同标题商品或多张主图推断。仅看见2个选项时显示“至少2色”，不冒充完整颜色总数。Pinterest 普通图片没有商品颜色选项时为未知。列表页未展示颜色信息时可以打开商品详情页采集，仍未识别的可在在线表格手动填入确认的数量；JSON 和 CSV 会保留颜色信息。复色信息尚未重新确认的已有记录会保留上次已识别信息。

## 自动点击下一页

打开商品列表 → 选择翻页方式“自动点击下一页” → 设置加载轮数和图片上限 → 点击“开始自动采集”。轮数包含当前页，例如10轮最多读取当前页加后续9页。进度会显示“正在点击下一页”。末页按钮禁用、未找到可用按钮、连续3轮无新增或遇到验证时停止并保留记录。

Pinterest 首页为无限推荐流，通常没有下一页按钮，应选择“自动识别”或“仅滚动加载”。不识别自定义分页控件时会提示，不会随意点击页面上其他按钮。每日定时采集沿用保存的翻页方式与上限。
