# 妙手批量上架助手（Temu服饰）

Windows EXE：`MiaoshouTemuTool.exe`，不需安装 Python。此版本生成妙手服饰类批量导入表，不会登录ERP或点击发布。

## 使用

1. 选择Temu导出的SKU CSV（含产品ID、产品名称、图片链接、产品规格、供货价、尺寸及重量等字段）。
2. 选择保存目录。妙手官方服饰类导入模板已内置，也可以选择同格式模板。
3. 默认产地为“中国-江西省”，定制品为“否”，敏感属性为“否”。
4. 可填写统一CNY供货价覆盖全部SKU；留空则保留源文件每个SKU供货价。
5. 点击“读取SKU并核对标题”，逐商品填写英文标题。已知测试商品预填译文，其余不会猜测翻译。
6. 点击“生成妙手上传表格”，输出新文件，不覆盖已有文件。
7. 到妙手导入生成的XLSX，核对类目属性、尺码及其他平台要求，再发布。

## 映射规则

- 主编号取源产品ID（缺失时取主货号），同一个产品保持相同编号。
- 主货号、平台SKU、颜色、尺码、价格、包装尺寸、各尺码毛重/净重按源CSV填写。
- 产品素材图、颜色图、外包装图片直接采用源链接，不重新上传、不替换。颜色图为空才依次回填源轮播图/预览图，并记录提示；仍为空则停止生成。
- 外包装形状、类型和图片均以本次源CSV为准，不沿用旧套装固定图片。
- 类目按完整类目路径在模板查找表中匹配，不匹配时提示用户导入后选择。
- 建议售价自动按最终供货价（申报价）的5倍填写，币种CNY。供货价先按模板限制截取至两位小数。未知类目属性、尺码测量数据等保持空白。
- 保留官方模板第一列、第二行说明、类目及包装清单查找表，清除示例产品。
- CSV内店铺ID、店铺名、JIT库存等没有对应导入字段的数据不会输出。

“本地图片处理 / 原套装工具”保留之前的独立图片排序、裁切、ImgBB上传和店小秘输出功能；它的输出仍是旧店小秘格式。当前妙手模式直接读取SKU CSV，不会将新印花图片自动套到CSV里的旧图上。生成妙手新品前需先在源数据中填好对应图片链接。

## 构建

Windows 双击 `windows/build-exe.cmd`，输出 `dist/MiaoshouTemuTool-Windows.zip`，需Python3.12+与联网安装依赖。GitHub Actions 的 Build Windows EXE 成功后也可下载同名artifact。

测试覆盖CSV字段映射、默认值、价格覆盖、每尺码重量、图片链接原样保留和模板结构。实际Windows界面运行、妙手平台导入与发布仍需实机验证。
