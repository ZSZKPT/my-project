# 飞凡上架：图片自动处理版

## 主流程

选择产品模板 → 导入本地图片与印花名称 → 自动排序/裁切 → 上传ImgBB取在线链接 → 自动填写妙手服饰表 → 用户到妙手批量手动导入、选择尺码表/属性并发布。

软件默认打开图片处理窗口，不需要先从ERP导出SKU CSV。已经有SKU导出文件的用户可以点击“已有SKU CSV转换工具”。软件不会自动登录ERP或点击发布，表格生成完成不代表商品已上架。

## 使用

1. 选择“运动短袖套装（内置）”或已保存的其他模板。
2. 选择图片目录：单个货号文件夹，或包含多个货号子目录的父文件夹。不要将输出目录放到输入目录中。
3. 扫描货号；逐行填写印花名称，或导入含“货号、印花名称”的Excel/CSV。
4. 填写统一申报价CNY，建议售价自动为最终申报价的5倍。
5. 填入自己的ImgBB API Key，选择输出目录，开始处理并确认图片公开上传。密钥不保存。
6. 等待日志显示“表格已生成，待手动导入”，在输出目录获取 `妙手导入.xlsx`。
7. 到妙手批量手动导入，选择适用的尺码表、补充类目属性，核对后发布。

如果上传失败，软件会提示停止，保留已生成的本地文件；不会把失败标记为表格完成，远端已上传图片不自动删除。当前无跨运行上传续传，重新执行可能重复上传。ImgBB的额度和可用性以服务商为准。测试中使用模拟上传验证数据流，未用真实密钥实际上传。

## 多产品模板

默认模板名称：**运动短袖套装**。

- 类目29046；尺码S/M/L/XL/XXL；包装25×20×1cm；毛重200g。
- 中文标题：女士圆领短袖2件套{print_name}印花圆领T恤+短裤；已含“印花”的名称不会重复追加。
- 英文标题可在模板中编辑；默认采用通用套装英文标题加货号，不自动翻译印花名称。
- 产地中国-江西省；非定制品；非敏感属性。
- 外包装长方体、软包装+软物，使用此前确认的固定包装图链接。

点击“编辑 / 另存模板”创建新模板，可修改名称、中文/英文标题规则、类目、颜色、描述、固定包装及尺码尺寸重量。尺码参数编辑为JSON，每个尺码包含size、length_cm、width_cm、height_cm、weight_g，净重net_weight_g可选。

每次保存创建新模板，不覆盖旧模板；使用下拉列表切换。自定义模板保存在本机 `%APPDATA%\MiaoshouTemuTool\templates`，关闭/更新软件后仍可使用，也支持导入模板JSON。不会保存密钥。每次运行选择一个模板，一批可处理多个货号；不同款式请切换模板分批执行。

## 图片和输出

“前”图片优先，组内按自然文件名顺序排列；第一张作为主图，其余跟随。原图不覆盖。默认另存主图居中裁切的1000×1000素材图，也可选800/1200；800可能不符合某些导入要求，裁切构图需核对。

自动上传处理后的商品图和独立素材图，将返回的在线链接直接填入妙手“颜色图”和“产品素材图”；固定包装图片保持模板设置。每尺码一行，主编号和主货号为文件夹货号，SKU为货号-尺码。输出目录另存图片链接CSV、模板快照JSON及妙手XLSX。

手动模式也可先处理图片，在图片链接CSV中填写已上传链接（轮播图以 | 分隔），下次选择该CSV生成表格。不会把本地路径填入在线链接字段。

官方模板第一列、第二行填写说明及查找表保留，示例商品与样例超链接清除。未提供的类目属性和尺码测量表不会猜填。

## Windows构建和测试

Windows双击 `windows/build-exe.cmd`，输出 `dist/飞凡上架-Windows.zip`；本机打包需Python3.12+和网络。最终EXE不需要安装Python。

GitHub Actions构建并启动EXE检查内置模板，产物名为 `FeifanShangjia-Windows`。数据流测试覆盖两个本地货号、模拟上传后生成10行SKU、1000方形素材链接、29元申报价/145元建议售价、多模板存取及不保存密钥。真实ImgBB上传与妙手平台导入需在用户电脑验证。

## 界面

新版采用深色页头与浅色分区，左侧可滚动设置模板、图片目录、申报价和上传方式；右侧展示货号/印花名、上传进度、运行日志及完成状态。输出目录创建后可直接点击打开。显示“表格已生成 · 待手动导入”才代表Excel生成成功；失败时查看日志。进度为当前运行过程，不代表ERP发布进度。

## 印花填写缩略图

扫描图片目录后，每个货号行显示按排序选定的第一张主图缩略图，右侧填写印花名称。预览保留图片比例并处理EXIF方向，不修改原图。点击缩略图打开大图，按Esc关闭。损坏图片显示“无法预览”，不影响其他行显示。刷新目录后重新生成预览，原有已填印花名按货号保留。

## 同名商品

不同货号允许使用相同的印花名称与中文标题，不强制在标题加货号。图片模式仍按文件夹货号填写不同主编号、主货号及SKU，同名商品分别输出，不按标题合并；英文标题与图片按各货号保留。SKU CSV模式保留源产品ID分组。相同货号重复或同一商品尺码重复仍会报错。平台实际分组结果需导入后核对。

印花列表支持鼠标滚轮，鼠标在缩略图、货号或印花输入框上都可滚动；左侧设置区也独立支持滚轮。点击新图片时自动关闭上一张大图预览，始终保留一个预览窗口，关闭或按Esc可退出。

## 数字填写提示

图片处理模式的统一申报价必须填写。支持29、29.90、全角数字、29元、￥29.90和29 CNY。不要使用逗号作小数点或千位分隔。空值、非数字、零/负数会用中文指出申报价问题，并定位到输入框；包装尺寸和重量错误会指出尺码和字段。不会再直接显示Python的字符串转数字错误。
