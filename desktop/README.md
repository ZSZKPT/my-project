# Windows 桌面 EXE

界面支持选择本地图片目录、手动填写每个货号的印花名、统一申报价、商品导出模板及创建导入模板。

图片名含“前”排在前面，其余按文件名自然排序（细节2先于细节10），第一张作为主图。复制转换为带序号的 JPG，不改原文件；生成第一张主图的居中方形裁切，默认1000×1000，可选800（可能不满足导入要求）。请核对构图、透明图片和颜色效果。只处理货号目录的直接子文件。

每次输出新目录：整理图片、图片链接 CSV、模板配置 JSON，以及链接齐全时的店小秘导入 XLSX。每尺码一行，全部使用界面输入的价格。商品属性、类目和尺码表需导入后补齐，不自动发布。输入商品模板只读取共用颜色、尺码、包装尺寸、重量、详情；标题规则由界面填写，不沿用原模板中的平台ID。

## 生成 EXE

在 Windows 双击 `windows/build-exe.cmd`，需安装 Python 3.12+ 并联网。输出 `dist/TemuImportTool.exe`，该单文件可在同架构 Windows 电脑运行，不需另装 Python。尚未验证 Windows 实机运行。

也可在 GitHub 仓库 Actions 的 Build Windows EXE 工作流成功后，从 Artifacts 下载 `TemuImportTool-Windows`。构建是否成功以工作流结果为准。源码 ZIP 不包含已经构建的 EXE。

## 自动生成在线链接

图片必须上传到图片存储服务。内置可选 ImgBB 上传适配器，需用户 API Key，并在上传前确认公开图片；密钥仅留内存，不保存。此适配器尚未实际上传验证，免费政策和额度以服务商为准。上传失败时保留已处理文件和此前已完成货号的 CSV，已上传远端文件不会自动删除；无自动重试，避免重复上传。

默认手动模式不联网，将图片上传到店小秘图片空间后，在 CSV 填入直链（轮播图用 | 分隔），再次选择该 CSV 导出 Excel。自动对接店小秘、COS、OSS、R2 等仍需相应上传接口和授权配置，当前未实现。
